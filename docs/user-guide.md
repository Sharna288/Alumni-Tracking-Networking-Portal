# User guide

1. Install dependencies and start with `npm start`; open the local URL.
2. Sign in with a demo account or register. Alumni registrations are pending verification.
3. Use Alumni directory filters to find verified profiles. Select Connect to request a connection.
4. Alumni can publish job or internship opportunities. Students can browse and apply using any provided application link.
5. Browse events to register or cancel. Request mentorship with a short message.
6. Administrators can sign in to review alumni, manage announcements/events, and export CSV.

Every seeded person and opportunity is fictional demonstration content. Update your profile carefully; only administrators can mark an alumni profile verified.
